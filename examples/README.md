# Вымышленные демонстрационные данные

Файлы before.txt и after.txt полностью синтетические. Они содержат примеры сохранённой и переформулированной функции, передачи функции, функции без найденного соответствия, новой функции, возможного дублирования, контрольной роли и фразы с prompt injection. Эти тексты не описывают реальные процессы Казахтелекома.
